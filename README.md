## What the Extension Does

AI Context Injector is a Chrome extension for anyone who repeatedly provides instructions, notes, or other background information to AI assistants. Create a collection of reusable snippets, keep them organized, and insert them into supported chat interfaces without switching away from the browser.

The extension suits developers and productivity-oriented workflows that depend on repeatable prompts, reference material, and task-specific fragments. Your snippet library remains on your machine because the extension relies on local browser storage rather than an outside account or synchronization service.

## Key Capabilities

- Build a personal library of AI context snippets
- Send a saved snippet to a supported chat tool with a single click
- Create flexible prompt templates with variable placeholders
- Combine several selected snippets in one injection
- Arrange snippets in folders
- View built-in usage statistics
- Pin or star frequently used entries
- Copy an existing snippet to create a variation
- Run actions through a keyboard shortcut

## Using AI Context Injector

The basic process is:

1. Save a prompt, recurring instruction, note, or system message as a snippet.
2. Insert placeholders for details that will change between tasks.
3. Put related entries into folders and star or pin the ones you use most.
4. Visit a supported AI chat page and inject one entry or a selection of snippets.
5. Make quick adjustments in the task field before sending the prepared context into the conversation.

For example, you can:

- Create a code-review context snippet
- Include variables for the project name and technology stack
- Select several related snippets together
- Insert them into ChatGPT, Claude, Gemini, or Grok
- Reuse the same context setup the next time the task comes up

## Settings and Data

The extension interface contains the main configuration controls. Chrome stores snippets, folders, favorites, usage statistics, and exported data locally.

Before injecting a template, provide values for its placeholders so the resulting context reflects the task at hand. Where Chrome supports them, keyboard shortcuts and browser context-menu actions can be managed through the extension controls.

## Frequently Asked Questions

**Is an account needed?**  
No external account is indicated in the provided product profile. The extension operates with local storage only.

**Where does the extension keep my information?**  
Snippets and associated settings are saved in the browser's local storage.

**Can I transfer my snippet library to another computer?**  
Yes. Export the collection, then use the import tools on the other machine.

**Why might injection fail on a page?**  
Check that the page is supported, reload the tab, and verify that Chrome has the required extension permissions.
